📖 Como jogar

  • Ficha: HABILIDADE = 1 dado + 6 · ENERGIA = 2 dados + 12 · SORTE = 1 dado + 6. Os valores iniciais são os máximos.
  • Leia e escolha: cada parágrafo tem escolhas que levam a outro parágrafo. Alguns caminhos são becos; outros têm tesouros.
  • Combate: a cada rodada, você e o monstro rolam 2 dados + HABILIDADE (Força de Ataque). Quem tirar mais fere o outro em 2 de ENERGIA. Empate = ninguém se machuca.
  • Sorte no combate: depois de um golpe, você pode Testar a Sorte: 2 dados ≤ SORTE atual = sorte. Se você feriu: sorte = dano 4, azar = dano 1. Se foi ferido: sorte = perde só 1, azar = perde 3. Cada teste gasta 1 de SORTE.
  • Fugir: só quando o texto permitir; custa 2 de ENERGIA.
  • Provisões: você começa com 10. Comer (+4 ENERGIA) só em lugares seguros, uma refeição por vez.
  • Poção: escolha uma no começo (Habilidade, Energia ou Sorte). Usa 1 vez, restaura o valor inicial.
  • ENERGIA 0 = fim. Mas o papai é bonzinho: dá pra voltar ao último ponto de retorno.
  • O jogo salva sozinho neste aparelho.
